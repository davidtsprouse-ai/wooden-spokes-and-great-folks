# Wooden Spokes and Great Folks

Marketing website for a stagecoach (and historic horse-drawn vehicle) restoration workshop in Poway, California.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Custom SVG logo (`public/logo.svg`)

## Pages

- `/` — Home (hero, story, highlights, process, CTA)
- `/services` — Restoration, conservation, custom builds, maintenance, consultation
- `/gallery` — Placeholder craft imagery (Unsplash; clearly labeled, not fake client work)
- `/about` — Workshop story and values
- `/contact` — Mailto-backed inquiry form + Poway location

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Brand

Warm wood tones, cream/parchment backgrounds, deep burgundy and forest accents. Classic serif headlines (Libre Baskerville) with clean sans body (Source Sans 3). Premium craftsmanship — not kitschy Wild West.
